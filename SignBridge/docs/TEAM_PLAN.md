# Suggested four-member work split

1. **Member 1 — Dataset & preprocessing:** dataset provenance, consent, label definitions, sample collection, quality checks.
2. **Member 2 — Recognition model:** landmark features, classifier training, validation, class-wise metrics.
3. **Member 3 — NLP & application:** Streamlit integration, gloss sequence, optional FLAN-T5, speech output.
4. **Member 4 — Testing & evaluation:** test execution, held-out evaluation, BLEU/chrF, latency measurements, report integration.

All members should review the complete architecture and jointly validate sign labels with an ISL-fluent reviewer.
